# unraid-templates

Unraid Community Applications templates. Install from the Apps tab, or add this repository under Docker → Template Repositories.

- `templates/`: one XML template per app
- `images/`: template and profile icons
- `docs/`: longer guides for templates that need one
- `.github/workflows/`: builds images for apps that publish none of their own, at each new release tag

Report template or Unraid problems in this repository's issues, and problems with an app itself to its own project.
